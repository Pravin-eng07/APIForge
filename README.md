# ⚡ APIForge

### Test APIs. Inspect Responses. Track Requests.

APIForge is a lightweight API Testing Playground built with React.js.
It allows developers to send HTTP requests, inspect API responses,
format JSON, copy responses, and maintain request history directly
in the browser.

## 🚀 Features

- GET, POST, PUT and DELETE requests
- Custom API URL support
- Custom JSON headers
- JSON request body
- JSON formatting
- Response status and response time
- Response viewer with formatted JSON
- Copy response to clipboard
- Request history
- LocalStorage-based history persistence
- Load previous requests from history
- Ctrl + Enter keyboard shortcut
- Responsive design for desktop and mobile
- Clean light developer-tool interface

## 🛠️ Tech Stack

- React.js
- Vite
- JavaScript
- Fetch API
- HTML5
- CSS3
- LocalStorage

## 📸 Project Preview
